# Fickle FOSS

Supports **fickle giving** to FOSS projects.

Fickle giving is a low-commitment approach to donating money. Instead of 
committing to particular recipients, fickle givers commit to donating 
regularly but the recipients are chosen at the time of giving.

As fickle givers give to a lot of different recipients, Fickle FOSS helps
you keep track of how much you have given and to whom.
